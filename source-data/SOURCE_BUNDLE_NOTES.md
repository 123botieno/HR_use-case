# Ethiopian job descriptions and fictional CV source bundle

`Ethiopia_15_Public_Sector_JDs_750_CVs/` preserves the available original source bundle, including its original README, job index, candidate manifest and DOCX files. All CVs are synthetic, not real applicant records. Job descriptions are source-faithful paraphrases with source URLs, as described in the original README.

## Actual file coverage

- The original bundle name and candidate manifest refer to **750 candidates across 15 jobs**.
- The supplied files contain **700 CV DOCX files and 14 JD DOCX files**.
- The JD-13 (2nd Cook) folder and its 50 candidate CVs are missing from the source bundle. They have not been fabricated or silently removed from the original manifest.
- One JD-15 CV was unreadable during workshop extraction, leaving **699 readable CVs across 14 available jobs** in the workshop CSV. The source file is preserved here as supplied.

For the workshop, use `job-matching-fairness/data/candidate_cvs/candidates.csv`. See `job-matching-fairness/data/SOURCES.md` for extraction details, simulation assumptions and source/license limitations.

This source bundle is included for traceability; it does not change the workshop applicant pool or its saved results.
