# Earlier experimental LLM comparison

An experimental run completed on 15 October 2026 using a provider configuration from before the OpenRouter conversion. Its source-derived JD rubrics were unconfirmed. The response cache, CV text, and generated run outputs remain local and are excluded from Git.

The historical notes recorded 42 completed JD/method combinations (14 vacancies × LLM, BM25, and TF-IDF), 210 shortlist entries, and 2,756 accepted evidence citations checked against literal CV text. Those figures describe that earlier local run only; its underlying reports are not in this repository and the run is not reproducible without the original data, cache, and provider setup.

Independent recruiter judgments were not supplied, so the experiment did not establish which ranking method was most accurate. Do not treat the historical output as validated hiring advice. Current LLM configuration and run instructions are in [`07-job-matching/llm/README.md`](../07-job-matching/llm/README.md).
